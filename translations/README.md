# FS25 Mod Center translations

Thank you for helping translate FS25 Mod Center.

The official English reference catalog is [`en-US.json`](en-US.json). Use it as the source for every new language.

## How to contribute

1. Copy `en-US.json` and rename it using the locale code for your language, for example `de-DE.json`, `fr-FR.json` or `es-ES.json`.
2. Keep every JSON key exactly as it is.
3. Translate only the text values on the right-hand side.
4. Update only the `_meta` values for `language`, `code` and `author` as appropriate. Keep the file structure unchanged.
5. Do not remove entries, rename keys or add unrelated keys.
6. When the translation is ready, submit it through the dedicated translation contribution form in GitHub Issues and attach the translated JSON file.

For a small correction or terminology suggestion, you can also use the same form and provide the original key/text together with your proposed translation.

## Important

The English catalog is the canonical reference. If a new FS25 Mod Center version adds or changes interface text, translators should always compare their language file with the latest `en-US.json` before submitting an update.

# Traduzioni di FS25 Mod Center

Grazie per contribuire alla traduzione di FS25 Mod Center.

Il catalogo inglese ufficiale di riferimento è [`en-US.json`](en-US.json). Deve essere usato come base per ogni nuova lingua.

## Come contribuire

1. Copia `en-US.json` e rinominalo con il codice locale della lingua, ad esempio `de-DE.json`, `fr-FR.json` o `es-ES.json`.
2. Mantieni esattamente tutte le chiavi JSON.
3. Traduci soltanto i testi a destra delle chiavi.
4. Modifica nella sezione `_meta` solo i valori `language`, `code` e `author` quando necessario. Mantieni invariata la struttura del file.
5. Non eliminare voci, non rinominare chiavi e non aggiungere chiavi non previste.
6. Quando la traduzione è pronta, inviala tramite il modulo dedicato alle traduzioni nelle GitHub Issues e allega il file JSON tradotto.

Per una singola correzione o un suggerimento terminologico puoi usare lo stesso modulo, indicando la chiave/testo originale e la traduzione proposta.

## Importante

Il catalogo inglese è il riferimento canonico. Quando una nuova versione di FS25 Mod Center aggiunge o modifica testi dell'interfaccia, è necessario confrontare il file della propria lingua con l'ultima versione di `en-US.json` prima di inviare un aggiornamento.
