**One library. All your maps.**

# English

## 1. Before you start

FS25 Mod Center organizes the ZIP mods stored in your Farming Simulator 25 profile folders.

For safer operation:

* Close Farming Simulator 25 before activating a profile.
* Use a dedicated folder for the centralized Library.
* Configure a Backup folder before replacing, removing or updating mods.
* Do not disconnect drives containing profiles, the Library or backups while an operation is running.

## 2. Initial setup

At first launch, FS25 Mod Center guides you through the initial configuration.

1. Add one or more folders containing your FS25 mods.
2. Give each folder a recognizable profile name, usually based on its map.
3. Choose an empty or dedicated folder for the centralized Library.
4. Start the initial scan.
5. Wait for the analysis and Library creation to complete.

The first scan may take several minutes depending on the number and size of the mods and the speed of the selected drive.

## 3. Overview

The Overview displays:

* Connected profiles
* Catalogued mods
* Unused mods
* Mods found in different versions
* Space occupied by the Library
* Backup availability
* Recent changes requiring attention

Notifications appear at the top of the application. When an action is required, the corresponding command remains available in the lower contextual bar.

## 4. Profiles

Each profile represents a folder containing the mods used for a specific map or game configuration.

From the Profiles section you can:

* View the mods contained in each profile
* Search and filter mods
* Add mods available in the Library
* Remove mods safely from a profile
* Update mods to the newest local version
* Rename or remove a profile from Mod Center
* Activate a profile for the next FS25 launch

Removing a profile from Mod Center does not delete its physical folder or the mods it contains.

### Activating a profile

The **Activate profile** command tells Farming Simulator 25 which mod folder to use at the next launch.

Farming Simulator 25 must be closed. Before changing `gameSettings.xml`, Mod Center automatically saves a safety copy.

## 5. Library

The centralized Library keeps one physical copy of every recognized mod.

If the same mod exists in multiple profiles, Mod Center avoids unnecessary duplicates. When different versions are found, the most recent local version is retained in the Library.

Building or aligning the Library does not move, rename or delete the ZIP files stored in the original profile folders.

Use **Align Library** whenever Mod Center detects external additions, removals or modifications.

## 6. Different versions

The **Different versions** section lists mods installed in more than one version across your profiles.

You can choose which profiles to update using the newest local version available on the computer. A valid Backup folder is required before any version is replaced.

## 7. Updates

The Updates section can check recognized mods through official ModHub pages or public GitHub repositories.

Depending on the available information, a mod may be:

* Up to date
* Update available
* External
* To be reviewed
* Not found
* No longer available

Before installing an update, Mod Center verifies the downloaded ZIP and preserves the currently installed version in the Backup folder.

Sources that cannot be identified automatically can be assigned manually or marked as external.

## 8. Collections and favourites

Collections organize mods without creating additional copies or changing profile folders.

You can use them for machinery groups, map themes, work categories or any personal organization. Deleting a collection removes only its organization, not the mods.

## 9. Backup

Configure the Backup folder before performing protected operations.

The Backup section allows you to:

* Create manual backups
* Browse automatic and manual backups
* Restore archived mods
* Delete individual backups
* Delete all backups belonging to a profile
* Enable automatic cleanup of older backups

Restoring a mod does not overwrite the current version without protection: the version being replaced is archived first.

Deleting a backup is permanent and cannot be undone.

## 10. Steam and non-Steam editions

Profiles, Library, Backup, classification and update checks can also be used with non-Steam editions of Farming Simulator 25.

The **Launch FS25** button currently supports Steam only. Other editions must be started from their usual launcher.

## 11. Reporting a problem

Open a report in [GitHub Issues](https://github.com/gigigames85-bit/fs25-mod-center/issues) and include:

* Windows version
* FS25 Mod Center version
* Operation being performed
* What you expected
* What happened
* Screenshots, when useful

# Italiano

## 1. Prima di iniziare

FS25 Mod Center organizza le mod ZIP presenti nelle cartelle profilo di Farming Simulator 25.

Per lavorare in sicurezza:

* Chiudi Farming Simulator 25 prima di attivare un profilo.
* Usa una cartella dedicata per la Libreria centralizzata.
* Configura una cartella di Backup prima di sostituire, rimuovere o aggiornare le mod.
* Non scollegare le unità che contengono profili, Libreria o backup durante un’operazione.

## 2. Configurazione iniziale

Al primo avvio, FS25 Mod Center accompagna l’utente nella configurazione.

1. Aggiungi una o più cartelle contenenti le mod di FS25.
2. Assegna a ogni cartella un nome riconoscibile, generalmente quello della mappa.
3. Scegli una cartella vuota o dedicata per la Libreria centralizzata.
4. Avvia la scansione iniziale.
5. Attendi il completamento dell’analisi e della creazione della Libreria.

La prima scansione può richiedere alcuni minuti. La durata dipende dal numero e dalla dimensione delle mod e dalla velocità dell’unità scelta.

## 3. Panoramica

La Panoramica mostra:

* Profili collegati
* Mod catalogate
* Mod non utilizzate
* Mod presenti in versioni differenti
* Spazio occupato dalla Libreria
* Disponibilità del Backup
* Modifiche recenti che richiedono attenzione

Le notifiche appaiono nella parte superiore dell’app. Quando è necessaria un’azione, il relativo comando resta disponibile nella barra contestuale inferiore.

## 4. Profili

Ogni profilo rappresenta una cartella contenente le mod utilizzate per una determinata mappa o configurazione.

Dalla sezione Profili puoi:

* Visualizzare le mod contenute in ogni profilo
* Cercare e filtrare le mod
* Aggiungere mod disponibili nella Libreria
* Rimuovere una mod dal profilo in sicurezza
* Aggiornare le mod alla versione locale più recente
* Rinominare o rimuovere un profilo da Mod Center
* Attivare un profilo per il successivo avvio di FS25

Rimuovere un profilo da Mod Center non elimina la sua cartella fisica né le mod contenute.

### Attivazione di un profilo

Il comando **Attiva profilo** indica a Farming Simulator 25 quale cartella mod utilizzare al prossimo avvio.

Farming Simulator 25 deve essere chiuso. Prima di modificare `gameSettings.xml`, Mod Center ne salva automaticamente una copia di sicurezza.

## 5. Libreria

La Libreria centralizzata conserva una sola copia fisica di ogni mod riconosciuta.

Se la stessa mod è presente in più profili, Mod Center evita i duplicati inutili. Quando rileva versioni differenti, nella Libreria mantiene la versione locale più recente.

La creazione o l’allineamento della Libreria non sposta, rinomina o elimina gli ZIP presenti nelle cartelle originali dei profili.

Usa **Allinea Libreria** quando Mod Center rileva aggiunte, rimozioni o modifiche eseguite dall’esterno.

## 6. Versioni diverse

La sezione **Versioni diverse** mostra le mod presenti in più versioni nei profili.

Puoi scegliere quali profili aggiornare utilizzando la versione locale più recente disponibile sul computer. Prima della sostituzione è necessaria una cartella di Backup valida.

## 7. Aggiornamenti

La sezione Aggiornamenti può controllare le mod riconosciute attraverso le schede ufficiali ModHub o repository GitHub pubblici.

In base alle informazioni disponibili, una mod può risultare:

* Aggiornata
* Aggiornamento disponibile
* Esterna
* Da verificare
* Non trovata
* Non più disponibile

Prima di installare un aggiornamento, Mod Center verifica lo ZIP scaricato e conserva nel Backup la versione attualmente installata.

Le fonti non riconosciute automaticamente possono essere indicate manualmente oppure contrassegnate come esterne.

## 8. Raccolte e preferiti

Le Raccolte organizzano le mod senza creare copie aggiuntive e senza modificare le cartelle dei profili.

Puoi utilizzarle per gruppi di mezzi, tipologie di lavoro, mappe o qualsiasi organizzazione personale. Eliminare una Raccolta rimuove soltanto la sua organizzazione, non le mod.

## 9. Backup

Configura la cartella di Backup prima di eseguire operazioni protette.

La sezione Backup consente di:

* Creare backup manuali
* Consultare backup automatici e manuali
* Ripristinare le mod archiviate
* Eliminare singoli backup
* Eliminare tutti i backup di un profilo
* Attivare la pulizia automatica dei backup meno recenti

Il ripristino non sostituisce una versione esistente senza protezione: la versione che sta per essere sostituita viene prima archiviata.

L’eliminazione di un backup è definitiva e non può essere annullata.

## 10. Edizioni Steam e non Steam

Profili, Libreria, Backup, classificazione e controllo degli aggiornamenti possono essere utilizzati anche con le edizioni non Steam di Farming Simulator 25.

Attualmente soltanto il pulsante **Avvia FS25** richiede Steam. Le altre edizioni devono essere avviate dal proprio launcher.

## 11. Segnalazione di un problema

Apri una segnalazione in [GitHub Issues](https://github.com/gigigames85-bit/fs25-mod-center/issues) indicando:

* Versione di Windows
* Versione di FS25 Mod Center
* Operazione che stavi eseguendo
* Risultato atteso
* Comportamento riscontrato
* Screenshot, quando utili
